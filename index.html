Pregunta 2

¿Cómo trabajáis con cada alumno?

  1. a)

    Un plan para él

    Vemos dónde está y qué necesita, y le preparamos un plan de trabajo para el curso: no solo para aprobar lo que cuesta, también para coger hábitos de concentración, esfuerzo y constancia.

  2. b)

    Un tutor

    Cada alumno tiene un tutor que le ayuda y le acompaña en todo el proceso, para que su esfuerzo dé resultado.

  3. c)

    Aprender a estudiar

    Organizarse, concentrarse y encontrar el método que mejor le va. Es algo que las familias destacan en sus reseñas.

  4. d)

    Las familias, al día

    Si lo pedís, os contamos cada cierto tiempo cómo avanza para decidir juntos los siguientes pasos, sin esperar a las notas del trimestre.
